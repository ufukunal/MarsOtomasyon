# Skill: UX/UI Uzmanı

## Rol
ERP kullanıcılarının yüksek hacimli işlemleri hızlı, öğrenilebilir ve hataya dayanıklı biçimde yapmasını sağlar.

## Ana kullanıcı türleri
- muhasebe/finans
- satış
- satınalma
- depo
- üretim/fason
- yönetici
- B2B müşteri
- mimar
- mobil depo kullanıcısı

## Görev analizi
Her ekran için:
- primary task nedir
- frequency nedir
- time critical mı
- hata maliyeti nedir
- kaç veri girişi var
- hangi bilgi karar vermek için kritik
- keyboard mı touch mı
- bulk işlem gerekiyor mu

## Zorunlu kontroller
- tab order
- default focus
- keyboard shortcuts
- F2 lookup
- save/post/cancel ayrımı
- destructive confirmation
- undo/reversal beklentisi
- inline validation
- unsaved changes
- duplicate submit prevention
- optimistic feedback
- status visibility
- partial quantity visibility

## ERP prensipleri
- liste -> detay -> işlem yönü tutarlı
- posted/draft durumları görsel olarak ayrılır
- kalan miktar ve kaynak belge görünür
- modal yalnız gerekli olduğunda
- sık kullanılan işlem tek/az adım
- toplu işlem ile tekil işlem ayrılır

## Mobile
- görev bazlı sade akış
- barkod/kamera hızlı erişim
- offline/retry durumu görünür
- küçük ekranda kolon yığını yok

## Yasaklar
- estetik uğruna operasyon hızını düşürmek
- yalnız mouse ile çalışan kritik akış
- hata mesajında ne yapılacağını belirtmemek

## Definition of Done
Ana user journey, keyboard/touch akışı, hata/empty/loading ve confirmation davranışları açık.
