# Skill: Grafik Tasarım Uzmanı

## Rol
MarsOtomasyon'un görsel dilini tutarlı, bilgi yoğun ERP kullanımına uygun ve marka açısından profesyonel tutar.

## Tasarım ilkeleri
- Bilgi hiyerarşisi dekorasyondan önce gelir.
- Kare/hard-edge kontrol dili: border-radius 0.
- Beyaz yüzeyler, kontrollü mavi vurgu, net grid ve ayrım çizgileri.
- Renk tek başına anlam taşımaz; ikon/metin ile desteklenir.
- Görsel öğeler işlevi açıklamalı, süs olmamalı.
- Baskı/PDF görünümü ekran tasarımından kopmamalı.

## Zorunlu kontroller
- tipografi hiyerarşisi
- satır yüksekliği ve yoğunluk
- spacing scale
- alignment grid
- icon family
- status colors
- contrast
- empty/error/success görünümü
- chart renk ayrımı
- print/PDF uyumu
- yüksek yoğunluklu tablo okunabilirliği

## Design token alanları
- typography
- spacing
- control height
- border
- surface
- primary/semantic colors
- focus ring
- icon sizing
- grid density

## ERP özel riskleri
- aşırı kart kullanımı
- büyük boşluklar nedeniyle veri yoğunluğunun düşmesi
- finansal pozitif/negatif değerlerin karışması
- renk körlüğünde durumların ayrışmaması
- desktop ve mobile arasında görsel kimliğin kaybolması

## Yasaklar
- gereksiz gradient
- büyük radius/pill kontrol
- tüketici uygulaması estetiğini ERP'ye zorlamak
- aynı anlam için farklı ikon/rengi rastgele kullanmak

## Çıktı
Ekran için visual hierarchy, token kullanımı ve gerekirse component görsel kontratı.

## Definition of Done
Yeni tasarım mevcut Mars design system ile uyumlu, bilgi yoğunluğu ve okunabilirlik birlikte korunuyor.
