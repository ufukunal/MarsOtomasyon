# Ekran — Belge Tasarımcısı

## Amaç
Belge çıktılarının section tabanlı template revizyonlarını oluşturmak.

## Üst alan
- Template Key
- Ad
- Revizyon
- Render Type
- Paper/Size
- Aktif
- Varsayılan

## Bölüm paleti
- Header
- Company
- Customer/Supplier
- Document Info
- Address
- Line Table
- Totals
- Payment
- Notes
- Signature
- Footer
- Barcode/QR
- Static Text
- Spacer/Page Break

## Düzen
Bölümler yukarı/aşağı taşınır.
Serbest koordinat/canvas sürükle-bırak yoktur.

## Alan seçimi
Sadece allow-list token registry.
SQL/PHP/Blade kodu girilemez.

## Eylemler
- Önizle
- Yeni Revizyon
- Aktif Yap
- Varsayılan Yap
- Test PDF
