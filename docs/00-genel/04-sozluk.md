# Sözlük

| Türkçe | Kod | Açıklama |
|---|---|---|
| Şirket | company | Tam izole tüzel birim. Resmi ve gayri resmi ayrı şirkettir. |
| Cari | contact | Müşteri ve tedarikçi tek kart, kategoriyle ayrılır. |
| Ürün | product | Her varyant ayrı kart. |
| Varyant grubu | variant_group | Ayrı kartları tek ürün gibi gösteren grup. |
| Set ürün | product set | Kendi stoğu yok, bileşenlerden hesaplanır. |
| Lokasyon | location | Depo, şube veya araç. |
| Stok hareketi | stock_movement | Stoğu değiştiren tek gerçek kaynak. |
| Rezerve | reserved | Stoktan düşmez, kullanılabiliri azaltır. |
| Karantina | quarantine | Satılamaz, kontrol bekleyen stok. |
| Belge | document | Teklif, sipariş, irsaliye, fatura ortak yapısı. |
| Kesinleştirme | posting | Sonrası değiştirilemez hale getirme. |
| Ters kayıt | reversal | Kesinleşmiş belgeyi iptal eden karşıt kayıt. |
| Dönem | posting_period | Ay bazlı kayıt penceresi. |
| Seri | number_series | Şirket + belge türü bazında sayaç. |
