# Foundation Migration Baseline

This directory is the canonical EF Core migration location for the Mars Infrastructure persistence assembly.

Rules:
- schema changes are introduced through EF Core migrations;
- each committed migration identifies the owning module and affected logical contract in its session/evidence record;
- runtime application credentials are not migration credentials;
- design-time migration tooling reads only `MARS_MIGRATION_CONNECTION_STRING`;
- connection-string values must not be committed, echoed, or copied into evidence;
- domain module tables/mappings are not introduced by Foundation implementation packages unless a later domain work package explicitly owns them;
- targeted raw Npgsql/SQL is exception-only under ADR-0002 and is not a parallel migration architecture.

## FW-IMP-004

Canonical migration folder:
- `src/Mars.Infrastructure/Persistence/Migrations/Foundation/`

First committed Foundation migration:
- `20260922095311_FwImp004FoundationPrimitives`

It owns only:
- `foundation.audit_events`
- `foundation.idempotency_operations`
- `foundation.outbox_messages`

The migration was generated by EF Core tooling from the committed model. It was not hand-authored as a parallel DDL path.

It does not create ERP domain module tables.

Migration execution against test/production PostgreSQL is not part of FW-IMP-004; this package verifies generation, model drift and generated SQL only.
